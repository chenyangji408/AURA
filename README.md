## 🎯 项目简介

AURA是一个基于 R Shiny 的交互式单细胞 RNA 测序数据分析平台，集成了先进的多模型辩论引擎，实现了智能化、自动化的细胞类型注释。

### 核心亮点

- 🤖 **多模型辩论引擎**：集成多个大语言模型，通过三轮辩论机制提高注释准确性
- 🎨 **交互式可视化**：无需代码只需与页面交互即可完成所有步骤
- 📊 **完整分析流程**：从数据加载、质控、降维、聚类到细胞注释的一站式解决方案
- 🗄️ **多数据库整合**：整合 CellMarker、PanglaoDB、gprofiler2、clusterProfiler 等生物学数据库
- 🔧 **候选词表自主构建**：LLM 结合五大知识库（PanglaoDB、CellMarker、scType、gprofiler2、clusterProfiler）自动构建组织特异候选细胞类型，支持自定义
- 📈 **批量处理**：支持批量模式、逐簇模式等注释策略

### 2. AURA 2.0 多模辩论引擎

#### 三轮辩论机制

```
第一轮：初审辩论
├─ 辩手A（Spark）：基于标志基因和知识库证据给出初步判断
└─ 辩手B（Ernie）：独立分析并给出自己的判断

第二轮：交叉质询
├─ 辩手B 质询辩手A 的观点
└─ 辩手A 质询辩手B 的观点

第三轮：裁判裁决
└─ 裁判（DeepSeek）：综合双方观点和证据，给出最终判断
```

## 🤖 AURA 引擎详解

### 工作原理

#### 1. 知识库构建

知识库构建器的核心任务是将单细胞数据转化为结构化的生物学证据，为大语言模型（LLM）提供可靠的推理基础。其构建流程包含以下六个步骤：

- **步骤1：标记基因提取。** 动态调用Seurat的`FindAllMarkers`函数，通过特定阈值（仅正向标记、min.pct=0.25、logfc.threshold=0.25）精准识别各细胞簇的差异表达基因。

- **步骤2：PanglaoDB匹配。** 将标记基因与PanglaoDB比对，计算匹配度并输出最相似的细胞类型（如高匹配度的CD8+ T细胞）。

- **步骤3：CellMarker检索。** 查询CellMarker获取相关的细胞类型与组织来源，并内置本地fallback机制以应对API限流。

- **步骤4：scType 组织特异性匹配。** 利用 scType 的组织特异 marker 组合规则，校验候选细胞类型与组织背景的一致性。

- **步骤5：通路富集分析。** 利用clusterProfiler执行GO和KEGG分析，揭示细胞簇的具体生物学功能特征。

- **步骤6：整合为SuperPrompt。** 将上述多维证据（标记基因、数据库匹配、文献支持与通路分析）结构化为SuperPrompt，作为后续大模型辩论引擎的直接输入，确保推理的全面性与准确性。

#### 2. 三轮辩论流程

**第一轮：初审辩论**

- 辩手A 和辩手B 同时接收相同的证据
- 各自独立分析并给出细胞类型判断
- 输出格式：JSON（包含细胞类型、理由、关键基因）

**第二轮：交叉质询**

- 辩手B 阅读辩手A 的判断，提出质疑
- 辩手A 阅读辩手B 的判断，提出质疑
- 重点关注：证据链完整性、替代解释、逻辑一致性

**第三轮：裁判裁决**

- 裁判综合双方观点和质询内容
- 评估证据权重和推理逻辑
- 给出最终判断和置信度

#### 3. 质量评估

传统单细胞注释评估通常采用简单的准确率（Accuracy）作为主要指标，但这种方法存在明显局限性：

1. **粒度不匹配问题**：参考标签（如"Memory CD4 T"）与预测标签（如"T cell"）可能处于不同的生物学层级，简单的字符串匹配会将层级差异误判为错误
2. **评估不公平性**：不同方法可能输出不同粒度的结果，粗粒度方法天然获得更高的"准确率"
3. **无法区分错误严重程度**：将"CD4 T"预测为"CD8 T"（同属T细胞谱系）与预测为"B cell"（完全不同谱系）的错误程度显然不同

参考GPTCelltype（Hou et al., 2024, Nature Methods）等顶刊论文的评估方法，aura实现了双粒度评估系统，同时报告粗粒度准确率和细粒度层级匹配结果。

**核心理念**：构建细胞类型本体树（Cell Type Ontology Tree），基于层级关系进行匹配评估。

## ❓ 常见问题

### Q1：API 调用失败怎么办？

**A：** 检查以下几点：

1. API 密钥是否正确
2. 网络连接是否正常
3. API 额度是否用尽
4. 尝试切换其他模型

### Q2：注释结果不准确怎么办？

**A：**

1. 检查标志基因质量
2. 调整聚类分辨率
3. 使用更专业的组织模板
4. 手动复核并修正

### Q3：如何调整候选细胞类型？

**A：** 在 **AURA分析**页面（候选词表由 LLM 结合知识库自动构建）：

1. 查看 LLM 结合知识库生成的候选细胞类型
2. 点击 "编辑" 调整候选类型和标志基因
3. 保存并应用

### Q4：如何导出结果？

**A：**  在执行完AURA分析之后可在AURA分析页面最下端导出CSV或者RDS格式的注释结果。
